# Images du site

Déposez ici les images réelles. Elles sont converties automatiquement au build
(AVIF, WebP et JPEG en plusieurs tailles) ; tant qu'un fichier manque, un visuel
provisoire dessiné en SVG s'affiche à sa place.

| Fichier | Usage | Conseil |
|---|---|---|
| `portrait.jpg` | Portrait de l'auteur (accueil, page « L'auteur ») | format portrait 4:5, 1200 px de large minimum |
| `covers/<slug>.jpg` | Couverture d'un livre (chemin indiqué par `cover` dans `data/books.json`) | 1200 × 1800 px (ratio 2:3) |

Formats acceptés : JPEG, PNG, WebP, AVIF. Les images de partage (Facebook, WhatsApp)
sont générées automatiquement à partir des couvertures.
